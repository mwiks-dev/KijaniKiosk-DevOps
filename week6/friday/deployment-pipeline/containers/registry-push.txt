=== Requirement 7: Versioned Push to the Private Registry ==

**Date:** 2026-08-23T07:43:22Z

A private Docker registry is running as a `registry:2` container secured with **htpasswd** basic authentication and exposed on **port 5001**. The registry is reachable from the host as `localhost:5001` and from inside Minikube as `host.minikube.internal:5001`. Minikube was started with the `--insecure-registry` option (Integration Challenge F). Registry credentials are stored only in the local Docker credential store and the Kubernetes Secret—they are never committed to this repository.
